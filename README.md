# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` – главная страница;
- `catalog.html` – каталог товаров (9 товаров, фильтры);
- `product.html`, `product-2.html` … `product-9.html` – подробные карточки товаров (у каждого товара своя страница);
- `order.html` – страница оформления заявки;
- `contacts.html` – контактная информация;
- `css/style.css` – файл стилей;
- `js/main.js` – файл JavaScript;
- `images/` – изображения товаров (SVG);
- `README.md` – описание проекта;
- `.gitignore` – список файлов, исключённых из Git;
- `sitemap.xml` – простая карта сайта;
- Open Graph-теги – базовая разметка для отображения ссылок.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- Flexbox (навигация, карточки, кнопки формы) и CSS Grid (сетка товаров, макет каталога);
- именование классов по методологии БЭМ.

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` – шапка сайта;
- `site-nav` – основная навигация;
- `site-main` – основное содержимое страницы;
- `breadcrumbs` – хлебные крошки;
- `hero` – первый экран главной страницы;
- `section` – универсальный раздел страницы;
- `aside-info` – информационный блок;
- `products-grid` – сетка товаров;
- `product-card` – карточка товара;
- `catalog-layout` – структура страницы каталога;
- `catalog-filters` – фильтры каталога;
- `order-dialog` – модальное окно заявки;
- `order-form` – форма заявки;
- `success-message` – сообщение об успешной отправке;
- `button` – кнопка;
- `site-footer` – подвал сайта.

Примеры элементов: `product-card__title`, `site-nav__link`, `order-form__input`, `breadcrumbs__current`.

Примеры модификаторов: `product-card--featured`, `product-card--discount`, `site-nav__link--active`, `button--primary`, `button--secondary`, `order-form__field--checkbox`.

## Позиционирование

- `position: relative` – карточка товара `.product-card` и галерея `.product__gallery`;
- `position: absolute` – бейджи `.product-card__badge` и `.product__badge`;
- `position: sticky` + `z-index: 100` – шапка `.site-header`;
- `position: fixed` + `z-index: 90` – кнопка «Наверх» `.to-top`;
- `position: absolute` – кнопка-крестик `.order-dialog__close` внутри модального окна (`position: relative`).

## Самостоятельные доработки

1. **Подробная карточка товара** (`product.html` и `product-2.html` … `product-9.html` – у каждого товара своя страница) – изображение с бейджем, артикул, цена, наличие, преимущества, блок «Доставка и оплата», описание, расширенная таблица характеристик (размеры, вес, комплектация, гарантия) и раздел «Похожие товары».
2. **Блок часто задаваемых вопросов** – блок `faq` на `<details>` и `<summary>`: 5 вопросов раскрываются по клику без JavaScript, у открытого вопроса подсвечивается рамка.
3. **Несколько вариантов карточек через БЭМ-модификаторы:**
   - `product-card--featured` – хит продаж (бейдж «Хит»);
   - `product-card--discount` – товар со скидкой (бейдж с процентом, красная цена, зачёркнутая старая цена);
   - `product-card--new` – новинка (зелёный бейдж);
   - `product-card--sold-out` – нет в наличии (приглушённое изображение, неактивная кнопка «Заказать»).
4. **Расширенный каталог** – 9 товаров в трёх категориях (Популярные, Новинки, Распродажа). У карточек есть изображения и категории, в фильтрах показано количество товаров, есть фильтр «Только в наличии» и счётчик «Найдено товаров».
5. **Собственная визуальная концепция «Лаванда»:**
   - фиолетовый основной цвет, тёплый оранжевый акцент и светлый сиреневый фон, все цвета заданы переменными в `:root`;
   - шрифт Manrope, крупные мягкие скругления и тени;
   - светлая шапка с меню-«таблетками», градиентный первый экран, тёмный подвал;
   - дополнительные состояния: карточки приподнимаются при наведении и подсвечиваются при фокусе с клавиатуры, кнопки «вдавливаются» при нажатии, у неактивных кнопок отдельный вид;
   - при включённом в системе режиме «уменьшить движение» анимации отключаются (`prefers-reduced-motion`).
6. **Улучшенное модальное окно:**
   - в окне показано название выбранного товара;
   - добавлена кнопка-крестик, окно закрывается кликом по затемнённому фону и клавишей Esc;
   - окно плавно появляется, фон размывается;
   - после отправки вместо формы появляется сообщение «Заявка отправлена!» с кнопкой «Готово», при повторном открытии форма снова чистая.
7. **Улучшенная доступность форм (в модальном окне и на `order.html`):**
   - обязательные поля отмечены звёздочкой, над формой есть пояснение;
   - под каждым полем выводится понятный текст ошибки («Введите e-mail в формате name@example.ru», «Введите телефон в формате +7 (900) 000-00-00» и т. д.);
   - ошибки связаны с полями через `aria-describedby` и зачитываются экранными дикторами (`aria-live`);
   - после отправки фокус переходит на первое поле с ошибкой, ошибка исчезает, как только поле исправлено;
   - у полей заданы `autocomplete`, поля на `order.html` сгруппированы в `fieldset` с `legend`;
   - кнопка «Заказать» в каталоге открывает `order.html` с уже выбранным товаром.
8. **Фиксированная кнопка «Наверх»** – есть на всех страницах, работает без JavaScript (ссылка `#top`), закреплена через `position: fixed`.
